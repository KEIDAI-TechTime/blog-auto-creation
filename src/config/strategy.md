# TechTimeブログ記事戦略ガイド

## 必須要件
1. 記事冒頭に3点要約を配置
2. 重要データ・リスク・落とし穴にcalloutを配置
3. 記事末尾に3点まとめを配置（シミュレーターリンク含む）
4. 内部ラベル（【中間誘導】等）は公開テキストに含めない
5. シミュレーターリンクは自然な文脈で誘導

## 記事構成
1. 導入（キャッチーな問題提起）
2. 表向きの成功・現状
3. 裏側の課題・問題点
4. 原因分析
5. 解決策・あるべき姿
6. TechTimeの提案（シミュレーター誘導）
7. まとめ

## トーン
- 専門的だが読みやすい
- 数字・固有名詞を使って具体的に
- 批判だけでなく解決策も提示

## シミュレーターURL
https://techtime-jp.com/simulator

## callout形式
重要な情報には以下の形式でcalloutを使用：

```
> **重要**
> ここに重要な内容を記載
```

```
> **注意**
> ここに注意すべき内容を記載
```

```
> **ポイント**
> ここにポイントとなる内容を記載
```

## 3点要約の形式（記事冒頭）
```
## この記事のポイント
- ポイント1
- ポイント2
- ポイント3
```

## 3点まとめの形式（記事末尾）
```
## まとめ
- まとめ1
- まとめ2
- まとめ3

詳しいコスト試算は[TechTimeシミュレーター](https://techtime-jp.com/simulator)でお試しください。
```
